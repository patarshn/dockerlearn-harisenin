Topic: Intro to Containerization & Docker

Goal:
Peserta akan mampu membuat Dockerfile serta membangun dan menjalankan aplikasi Node.js/Next.js di dalam Docker Container lokal. Siswa juga akan mengenali fungsi Docker Compose dalam menghubungkan aplikasi dan database (MySQL) sesuai tren industri.

Materi:
- Introduction to Containerization & Docker Concept (VM vs Container)
- Understanding Dockerfile, Docker Image, and Docker Container
- Hands-on: Writing Dockerfile for Node.js/Next.js App
- Hands-on: Building & Running Application inside Docker Container
- Demo: Intro to Docker Compose (Connecting Node.js & MySQL)
